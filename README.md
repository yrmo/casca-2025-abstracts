# CASCA 2025 abstracts

Published presentation abstracts from CASCA 2025, Confluences, McGill University, Montreal, 7–10 May 2025.

Source: the public program at <https://event.fourwaves.com/casca2025/abstracts>, linked from the conference archive at <https://cas-sca.ca/en>. Collected 2026-11-22.

341 published presentations. 276 are scheduled. 65 are published submissions with no session time. One unpublished submission was left out. Email addresses were left out.

The public program does not include presentation type, language, or the submitter's professional status, so those fields are not here.

## Files

- `abstracts.md` — readable list. Scheduled presentations come first, in program order. Unscheduled submissions follow, by submission number.
- `abstracts.csv` — the same records as a spreadsheet.
- `abstracts.json` — the same records as JSON.
- `analysis.ipynb` — tick plot of decolonize, white supremacy, anti-, colonial, racism, and ethnography across that order. Running it writes `keyword-ticks.png`.

Times are Eastern (`America/Toronto`).

Abstract text belongs to the authors. This repository collects what the public program already publishes.
